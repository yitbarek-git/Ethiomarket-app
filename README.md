# 🇪🇹 EthioMarket

**EthioMarket** is a full-stack web application designed to deliver a practical marketplace experience for users in Ethiopia.

The project is developed by **Yitbarek K.** as a software engineering project focused on demonstrating how modern frontend interfaces, backend services, REST APIs, and relational databases work together in a production-oriented architecture.

## 🚀 Project Overview

EthioMarket integrates a modern web frontend with a backend REST API and a MySQL database.

The application is designed to demonstrate:

- User-facing interfaces and experiences
- Product data management
- Backend business logic
- RESTful API design
- Database operations and data integrity
- Authentication and application security
- Responsive web design

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yitbarek-git/market-com.git
cd market-com
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file based on `.env.example`.

Add your local MySQL configuration and other required environment variables.

> **Security:** Never commit your real `.env` file, database passwords, API keys, or other secrets to GitHub.

### 4. Set up MySQL

Create the required database and tables using the project's database/schema files.

### 5. Start the application

Run the project's development server:

```bash
npm run dev
```
